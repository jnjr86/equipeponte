# EQUIPE PONTE — Project Instructions

## Project

Institutional website for a group of psychologists in São Paulo, Brazil.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No framework unless explicitly approved
- Static-site compatible
- Must be deployable to standard shared hosting such as Locaweb

## Design Direction

Create a premium, contemporary, human and welcoming experience.

The website should communicate:

- trust
- empathy
- professionalism
- sophistication
- calm
- credibility

Avoid generic healthcare and therapy website aesthetics.

Do NOT default to:

- generic wellness layouts
- excessive beige
- leaf illustrations
- hands holding each other
- generic meditation imagery
- excessive rounded cards
- excessive gradients
- cliché mental-health imagery

Prefer:

- strong editorial typography
- generous whitespace
- sophisticated grid
- high-quality photography
- subtle visual details
- intentional asymmetry when appropriate
- elegant micro-interactions
- strong typographic hierarchy

## UX

Prioritize clarity and low cognitive load.

Important actions must be easy to identify:

- understand who Equipe Ponte is
- understand services
- meet the psychologists
- understand approaches
- contact the team
- schedule/contact via WhatsApp when applicable

## Responsive

Mobile-first.

Support at minimum:

- mobile
- tablet
- notebook
- desktop
- large desktop

Do not simply shrink desktop layouts.

## Accessibility

Target WCAG 2.2 AA.

Always consider:

- semantic HTML
- keyboard navigation
- visible focus states
- sufficient contrast
- alt text
- accessible forms
- reduced motion
- proper heading hierarchy

## SEO

Every public page should have:

- unique title
- meta description
- semantic headings
- canonical URL
- Open Graph metadata where appropriate
- structured data where appropriate

Provide:

- sitemap.xml
- robots.txt

## Performance

Target Lighthouse 90+ where practical.

Prioritize:

- minimal JavaScript
- optimized images
- WebP/AVIF
- responsive images
- lazy loading
- optimized fonts
- minimal dependencies
- good Core Web Vitals

## Code Quality

Keep HTML, CSS and JS organized and readable.

Prefer reusable components/patterns over duplicated code.

Use CSS custom properties for:

- colors
- typography
- spacing
- radius
- shadows
- animation timings

## Design System

Maintain consistent:

- typography
- colors
- spacing
- grid
- buttons
- cards
- forms
- navigation
- imagery
- interaction states

Do not introduce new visual patterns without checking existing components first.

## Workflow

Before implementing a new page:

1. Understand its content and objective.
2. Check the existing design system.
3. Plan desktop and mobile behavior.
4. Implement.
5. Test responsive behavior.
6. Check accessibility.
7. Check visual consistency.
8. Check performance.

## Important

Do not redesign approved sections without being asked.

When a Figma reference exists, prioritize visual fidelity to the approved design.
